Fichiers d'exemple pour les onglets Carto et Graphiques, repris du projet
PLUME (même auteur) :

- france_departements.csv : un exemple par département français (code
  INSEE, population, budget, indicateurs) — pour l'onglet Carto, échelle
  « Département » ou « France métropolitaine ».
- france_communes.csv : le même type d'indicateurs par commune (35 000
  lignes) — pour l'onglet Carto, échelle « Commune ».
- monde.csv : indicateurs fictifs par pays (codes ISO alpha-3) — pour
  l'onglet Carto, échelle « Monde ».
- graphique.csv : petit jeu de données catégoriel à plusieurs séries —
  pour l'onglet Graphiques.

Données fictives, à des fins de démonstration uniquement.
