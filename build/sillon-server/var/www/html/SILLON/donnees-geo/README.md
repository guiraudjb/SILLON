Fonds de carte et référentiels géographiques français (millésime 2025),
repris tels quels du projet PLUME pour l'onglet Carto de SILLON :
communes, départements, régions, EPCI et un fond monde, ainsi que les
tables de correspondance commune/département et région/monde utilisées
pour la sélection en cascade et l'agrégation des données par code INSEE.
