      À propos de SILLON

      SILLON (Système d'Interrogation Local et Libre d'Outils Numériques) est la plateforme locale d'analyse de données de la direction : import de fichiers CSV en bases PostgreSQL typées, requêtage SQL libre, exécution de scripts Python/R isolés et partage des résultats — sans dépendre du lac de données national.

      Pour toute question d'installation ou de fonctionnement, consultez la documentation ci-dessous.
